Protocols & Standards

The reference page for agentic commerce protocols: what's newly emerging, and direct links to the official specs of the standards that matter most. Unlike the rest of this site, the Major protocols list isn't limited to the last two months, it's meant to stay accurate as the field settles.

New on Protocols

new or significantly evolved in the last two months
Beyond Automation: Defining Agentic Global Payments · Sunrate & Mastercard · Jul 24, 2026 PR Newswire →

Released at WAIC 2026 in Shanghai, one of the first payments-industry reports specifically on Agentic AI in B2B cross-border payments: frames cross-border payments as moving into a new "Autonomy" stage where agents independently orchestrate and optimize payment and treasury workflows within defined governance.

Agentic Commerce: A Primer for the Payments Industry · U.S. Payments Forum · Jul 22, 2026 GlobeNewswire →

Not a technical spec but a framework for merchants, issuers, networks and PSPs covering consent, security and interoperability, developed by the Forum's Emerging Payments and Payments Fraud working committees.

A-Comm Evidence Protocol · draft, open for comment · Jul 20, 2026 Digital Transactions →

A-Comm Technologies' draft standard for building an evidence record establishing the validity of AI-initiated consumer transactions, public comment period runs through Aug 14.

Ripple joins the x402 standard · Jul 15, 2026 CoinDesk →

A crypto-native rail backing the same standard as Visa and Mastercard, widening x402's settlement options beyond USDC on Base.

Financial Services AI Adoption Plan · UK HM Treasury · Jul 14, 2026 GOV.UK →

Government recommendations, not a live protocol: 10 recommendations across five themes including agentic payments, whose trust framework covers legal/liability, Know Your Agent protocols and machine-to-machine authentication - the UK currently has no legal definition of AI agent identity or agent-operator registry.

x402 Foundation · operational launch · Jul 14, 2026 TFTC →

The Linux Foundation declared x402 governance operationally live with 40 member organizations, moving it from a Coinbase project to industry-run infrastructure.

Unified Agent Protocol (UAP) · proposal, not yet launched · reported Jul 8, 2026 Business Standard →

NPCI is developing a framework to authenticate and register AI agents transacting over India's UPI - 22.71B transactions in June 2026 alone - within user-defined limits. Still needs an RBI regulatory nod before launch; included here as a proposal to watch, not a live protocol.

Visa Agent Score, Agentic Registry & Large Transaction Model · announced · Jun 10, 2026 PYMNTS →

Three new components under Visa Intelligent Commerce, unveiled at Visa Payments Forum 2026, aimed at unifying Trusted Agent Protocol with default AP2 compatibility.

Mastercard Agent Pay for Machines (AP4M) · launched · Jun 2026 Mastercard newsroom →

A new settlement layer under the Agent Pay umbrella built specifically for agent-to-agent microtransactions down to fractions of a cent.

Major protocols

the ones to focus on, with a direct link to their official spec
Every link below goes to the protocol owner's own documentation, GitHub repository or developer portal, not a third-party summary.
AP2 · Agent Payments Protocol · Google, donated to FIDO Alliance Specification →

Cryptographically-signed "Mandates" for delegated, verifiable agent payments. Open extension of A2A and MCP.

x402 · Coinbase, governed by the x402 Foundation (Linux Foundation) Specification →

HTTP-native micropayments reviving the dormant "402 Payment Required" status code, settled in stablecoins.

ACP · Agentic Commerce Protocol · OpenAI & Stripe Specification →

Open standard connecting buyers, agents and businesses to complete purchases. Originally powered OpenAI's Instant Checkout, which OpenAI ended in Mar 2026 after near-zero conversion; ACP now underpins discovery in ChatGPT instead, with merchants handling checkout in their own in-chat apps.

UCP · Universal Commerce Protocol · Google, Shopify + 20 partners Specification →

Vendor-neutral standard modeling the full shopping journey (checkout, identity linking, order lifecycle), not just payment.

MCP · Model Context Protocol · Anthropic, hosted by the Linux Foundation Specification →

Standardizes how agents reach external tools, APIs and data. The plumbing most commerce protocols build on top of.

A2A · Agent2Agent Protocol · Google, transferred to the Linux Foundation Specification →

How independent agents discover each other, negotiate, and exchange tasks and results as peers.

ERC-8004 · Trustless Agents · Ethereum Specification →

On-chain Identity, Reputation and Validation registries letting agents check counterparties before transacting.

Visa Trusted Agent Protocol · Visa Specification →

Cryptographically signed HTTP messages (RFC 9421) to recognize Visa-approved agents and validate their intent at checkout.

Mastercard Agent Pay · Agentic Tokens · Mastercard Specification →

Per-agent network tokens scoped to merchant, spend cap and time window, issued through the MDES token framework.

Verifiable Intent (VI) · Mastercard & Google, open-sourced Overview & spec →

Tamper-resistant, selectively-disclosed proof of what a user authorized an agent to do, protocol-agnostic across AP2/UCP.

Klarna Agentic Product Protocol · Dec 12, 2025 Klarna press →

Klarna's own product-level protocol for surfacing catalog data to shopping agents, run alongside (not instead of) UCP and Stripe's Shared Payment Tokens, a hedge against any single standard winning outright.

MPP · Machine Payments Protocol · Stripe & Tempo Specification →

HTTP-native machine-to-machine payments launched Mar 18, 2026: a client pays inline with its request via the native 402 status code, no API keys or pre-provisioned accounts, settling in stablecoins, cards or Bitcoin Lightning.

Ant International Agentic Mobile Protocol (AMP) · open-sourced Apr 28, 2026 PR Newswire APAC →

Ant Group's international arm (separate from domestic Alipay) open-sourced a payment framework built for mobile interfaces - wallets, super-apps and wearables - aimed at giving agents simple, secure integration to the 4.4 billion digital wallet users it says it can reach.

China bloc (UnionPay APOP, Alipay ACTP, JD A2P2) · Apr-May 2026 UnionPay press release →

China's payment giants are each pushing a competing standard rather than converging on one: UnionPay's Agentic Payment Open Protocol (live demo in Hong Kong, Apr 2, 2026), Alipay's Agentic Commerce Trust Protocol (300M agent transactions disclosed May 26), and JD.com's Agent Autonomous Payment Protocol (A2P2).

FACT · independent trust & compliance layer · Fime See the FACT page →

Not a payment protocol, a neutral trust layer sitting above all of the above: intent validation, continuous compliance monitoring, independent auditor agents.
